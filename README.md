# Finance Scoring
Составление рекомендации о выдаче или отказе в займе

## Один из вариантов решения классической задачи кредитного скоринга.
Дано:

Три файла с данными

Первый файл "bureau.csv" 
Содержит данные о клиенте. 
Тип аккаунта киента (вид займа, который ранее клиенту предоставлялся).
Какое время назад клиент пользовался услугами банка.
Текущий лимит клиента на карте
Максимальный баланс на счете за последние 12 месяцев
У каждого клиента свой id в базе, значит можно сделать вывод, что каждая строка уникальная для каждого клиента

Второй файл "previous_loans.csv"
Содержит данные о предыдущих данных киентов. Сумму займа, период на который выдавался займ. За какое время займ был закрыт.
Была ли просрочка по займу и если была, то на какой период.
В этом файле для одного клиента может встречаться несколько независимых строк.
Есть объединяющая колонка с предыдущим файлом (id клиента). На основании этой колонки будем делать соединение

Третий файл "transactions.csv"
Файл содержит информацию о финансовых операциях клиентов за поседнее время.
Категория операции (займ, депозит или другое). На сколько была рискованая операция.
В какие сроки проводилась.
Как и у предыдущих двух файлов общая колонка - id клиента, по ней можно сделать группировку.

Также даны тренировочный и тестовые данные в файлах train.csv и test.csv
Файл с тренировочными данными содержит истинное значение результата для тренировки модели.

## Обработка данных
По какой колонке будем производить финальную группировку определили при просмотре начальных данных.
Файл с предыдущими транзакциями необходимо сгруппировать для соединения с остальными файлами.
Это лучше всего делать путем создания новых признаков (максимальный займ, минимальный займ, средний размер займа, дата первого займа,
дата последнего займа)
Данные были получены в текстовом формате, возможно необходимо привести значения даты к типу даты и времени.
Категориальные колонки лучше для модели расщипить на несколько столбцов со значениями 1 и 0, так модель воспримет данные лучше.

После создания новых признаков необходимо проверить на взаимосвязь признаков.
